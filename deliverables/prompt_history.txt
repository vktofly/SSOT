As requested in the Task Brief, below is the structured prompt history demonstrating the advanced prompt engineering techniques used to guide the LLM in analyzing the data, designing the architecture, and building the SSOT prototype.

--------------------------------------------------
PROMPT 1: Chain-of-Thought (CoT) & Role-Playing for Data Reconciliation
--------------------------------------------------
TECHNIQUE: Persona Assignment, Step-by-Step Reasoning, Constraint Enforcement.

"Act as a Senior Data Analyst at BharatTrip. I am providing you with three datasets: Support_Tracker (refunds requested), Finance_Tracker (payouts processed), and Escalations (customer complaints). 
Do not just calculate the net difference. Think step-by-step:
1. Perform an ID-to-ID Database Join on `Booking_ID` across all three tables.
2. Identify 'Dropped Handoffs' (Present in Support, missing in Finance).
3. Identify 'Deduction Mismatches' (Support Refund Amount > Finance Payout Amount).
4. Identify 'Off-Tracker Leaks' by checking the Escalations for 'No Ref'.
Output only the exact integer counts for each failure point, followed by a 1-paragraph summary of the operational bottleneck."

--------------------------------------------------
PROMPT 2: Context Injection & Architecture Design
--------------------------------------------------
TECHNIQUE: Contextual Anchoring, Zero-Shot Generation, Output Formatting.

"Based on your previous analysis, the bottlenecks are WhatsApp leakage and manual handoff drops. Design a system architecture for a Unified Single Source of Truth (SSOT) driven by LLM Agents to solve this.
Constraints:
- You must include an 'AI Ingestion Agent' to parse messy unstructured text.
- You must include a 'Reconciliation Agent' with a Human-In-The-Loop (HITL) approval UI.
- Ensure the design mitigates financial compliance risks.
Output format: A Markdown table mapping the 'Operational Failure' directly to your proposed 'AI Engineering Solution'."

--------------------------------------------------
PROMPT 3: Complex Code Generation & Dynamic Routing
--------------------------------------------------
TECHNIQUE: System Instructions, Dependency Constraint, Fallback Logic.

"You are now a Senior AI Operations Engineer. Write a production-ready `app.py` using Streamlit to prototype the SSOT architecture we just designed. 
Requirements:
1. Build an Operations Telemetry Dashboard tracking active escalations.
2. Implement the AI Ingestion Agent using `google-genai` (gemini-3.5-flash). 
3. Hallucination Mitigation: If the LLM hallucinates an invalid travel route, the UI must explicitly flag it.
4. Dynamic API Key Routing: Build the app so it accepts BOTH an OpenAI API key or a Google Gemini API Key via the Streamlit sidebar. If OpenAI is provided, fallback to the REST API without requiring the `openai` python package to keep dependencies ultra-lightweight."
