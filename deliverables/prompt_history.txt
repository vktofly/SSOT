--- Prompt 1: Informal Request Parser ---
Role: AI Operations extraction agent for a travel company
Task: Analyze an informal message and return a valid JSON object.
Keys to extract:
- "agent_name": The name of the agency if identifiable, else null.
- "route": The flight/travel route (e.g., BLR-MAA, DEL-DXB), else null.
- "missing_reference": Boolean, true if they mention missing a ref number or PNR.
- "urgency": "High", "Medium", or "Low" based on the tone and wait time.
- "intent": "status_update" or "new_refund"

Input: "Hi, I cancelled booking for DEL-DXB last week and was told I'd get a refund. I haven't received anything and I don't have any reference number."
